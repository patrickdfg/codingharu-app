# 공개 홍보 첫 화면

2026-10-20. 기준: codingharu-app 25a8146.

## 변경

- 앱 루트 index.html을 공개 수업 소개 페이지로 구성. 상단 오른쪽 로그인·회원가입은 기존 인증 DOM을 포함한 native dialog를 연다.
- Three.js0.186.1의 로컬 모듈과 직접 만든 입체 코딩 큐브·궤도·별·위성, 마우스 반응. 원격 이미지·3D 에셋·CDN 실행 요청 없음.
- 블록 코딩·파이썬·AI 소개, 배우는 과정, 기존32차시 프로젝트 과정, 로그인/가입 진입을 연결.
- 첫 주소 방문 시 기존 세션·교안 열쇠가 있어도 홍보 화면 유지. 수업 버튼을 누르면 기존 인증 상태에 맞춰 이동. ?next= 경로는 기존처럼 인증 팝업으로 바로 연결.
- core.js·record.js·inject.js·서버는 그대로. 암호화 교안·실제 학생 기록·암호화 소금·비밀번호는 수정하지 않음.
- SHELL_CACHE는 신규 정적 자산 추가로4→5. home CSS/JS와 Three.js 모듈2개를 저장해 첫 화면의 오프라인 표시 지원.
- 모바일 해상도 제한, 화면 밖·백그라운드·인증 팝업 동안3D 중지. reduced-motion 기본 정지와 수동 재생/정지 버튼. WebGL2 미지원 시 CSS 대체 그림.
- 원래의 noindex,nofollow는 유지. 확인되지 않은 연락처·수강료·등록 실적 등은 추가하지 않음.

## 확인

`node test/interop.test.mjs`: 기존 암호화·복호화·파일 제외·비밀번호 변경 검증 통과.

Playwright와 설치된 Chrome 환경에서 `node tools/test-home.cjs`:

- 실제 Three.js WebGL2 첫 렌더링. 로컬 라이브러리 내부 import가 모두 존재하는 파일로 연결됨.
- 320/390/768/1280/1440px 가로 넘침 없음, 상단 계정 버튼 노출. PC·모바일 전체 화면과 로그인 팝업 이미지 직접 확인.
- 최초 화면의 인증 팝업 닫힘, Google 스크립트는 사용자가 인증을 열 때만 요청.
- 회원가입 번호 불일치 검사, 가입 신청 승인 대기 안내, 로그인 탭 복귀. 탭 방향키·Escape 닫기.
- 학생 로그인 오류·번호 초기화, 초기 기기 수업 비밀번호 확인. 무작위 시험용 키로 실제 암호화 fixture를 서비스워커에서 복호화하고 요청한 프로젝트/엔트리 수업으로 이동.
- 로그인 후 루트 재방문에도 홍보 화면 유지, 기존 세션에서 수업 버튼 이동, next 쿼리 로그인 팝업.
- 모의 Google callback→기기 등록→수업 열쇠→관리자 현황→교안 진입→로그아웃.
- 기록 기능이 꺼진 설정에서 기존 수업 비밀번호 진입 및 회원가입 안내.
- reduced-motion 정지·재생 버튼, WebGL 미지원 대체 그림과 로그인, 캐시된 오프라인 첫 화면, JavaScript 비활성 시 소개·안내 표시.
- pageerror 없음. 로그인/기록 API·Google은 모두 모의 응답이며 실제 계정에 가입 요청을 보내지 않음.

## 미확인

실제 Google 계정·실제 학생 계정 서버 왕복, 실물 Android 태블릿 GPU 성능·설치·오프라인은 사람이 확인해야 한다. 데스크톱3D 검사는 Chrome의 SwiftShader를 사용했다. 실제 인증 서버의 상태를 보장하는 시험은 아니다.
